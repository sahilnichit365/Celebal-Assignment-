# Week 6 - Apache Spark Data Processing

Objective

The objective of this assignment is to understand Apache Spark architecture and perform efficient data processing using PySpark. The assignment focuses on DataFrame operations, schema handling, filtering, transformations, lazy evaluation, and optimized file formats.

 Topics 

- Apache Spark Architecture
- Driver, Cluster Manager, and Executors
- Lazy Evaluation
- Directed Acyclic Graph (DAG)
- Reading CSV and Parquet Files
- Schema Inference
- DataFrame Transformations
- Filtering and Selecting Data
- Renaming Columns
- Data Type Casting
- Adding New Columns
- Handling Null Values
- CSV vs Parquet
- Predicate Pushdown
- Read → Transform → Filter → Write Pipeline
- Spark Performance Best Practices

Technologies Used

- Python
- PySpark
- Apache Spark
- Google Colab

Dataset

Customer Personality Analysis (marketing_campaign.csv)

Learning Outcomes

- Understand Spark Architecture
- Work with Spark DataFrames
- Apply Transformations and Actions
- Handle Null Values
- Compare CSV and Parquet
- Build Efficient Spark Data Pipelines
- Follow Spark Performance Best Practices
